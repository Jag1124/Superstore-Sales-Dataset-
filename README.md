# Advanced SQL Analysis, KPI Modeling & Variance Dashboard
## Project Overview
This project focuses on analyzing sales performance using SQL, Excel, and Power BI. It includes monthly sales analysis, performance variance calculations, growth metrics, and dashboard reporting.
## Objectives
- Perform advanced SQL analysis using CASE statements, HAVING clauses, and subqueries.
- Calculate monthly sales and month-over-month variance.
- Analyze sales growth and performance trends.
- Build an interactive Power BI dashboard.
- Present business insights to support decision-making.
## Tools & Technologies
- SQL
- Microsoft Excel
- Microsoft Power BI
- DAX
- Data visualization
## SQL Analysis
SQL queries were used to:
- Classify category sales using CASE statements.
- Filter aggregated regional sales using HAVING.
- Compare category sales against average category sales using a subquery.
- Identify top customers by total sales.
## Excel Analysis
The monthly analysis includes:
- Current Month Sales
- Previous Month Sales
- Sales Variance
- Growth Percentage
**Sales Variance = Current Month Sales − Previous Month Sales**
**Growth % = Sales Variance ÷ Previous Month Sales × 100**
## Power BI Dashboard
The planned dashboard presents:
- Monthly current versus previous sales
- Monthly sales variance
- Month-over-month growth percentage
- Key sales performance indicators
## Data Limitation
The available dataset does not contain a dedicated Profit column. Therefore, profit and profit-margin calculations are not included.
## Conclusion
This project demonstrates how SQL, Excel, and Power BI can be used together to analyze sales performance, identify trends, and communicate business insights through reporting and visualization.
